## Failure diagnosis

After all audio and all 241 finalize acknowledgements completed, the harness
waited 15 seconds for `metrics.actual_send >= 3,600,000`. That condition was never
met, causing `Soak sender failed: TimeoutError`.

Qwen calls `_reset_task_timeline()` on finalize
(`extension.py:250`). That method resets the base `audio_timeline` and
`last_reported_audio_duration` (`extension.py:318`). Base `actual_send` metrics are
computed from that timeline, so the reported value repeatedly restarts for each
recognition task rather than remaining cumulative for the extension session.
The log contains 240 decreases of this metric, a maximum of only 15,010 ms, and
a final value of zero. This is independent of the sustained-result observation:
results continued throughout the full audio-input period.

Fixing the cumulative metric accounting and rerunning this acceptance test remain
follow-up work. Do not interpret this run as a fully passing soak.
